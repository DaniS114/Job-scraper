We are looking for a Frontend Developer with a passion for frontend development to join our team and help build modern user interfaces for cloud security applications. If you enjoy working with React, designing intuitive user experiences, and collaborating closely with backend engineers, we want to hear from you.
Responsibilities:
· Design, develop, and maintain modern web user interfaces using React and TypeScript.
· Collaborate with backend engineers to integrate frontend applications with cloud-based services and APIs.
· Participate in the entire software development lifecycle, including planning, implementation, testing, and deployment.
· Contribute to UI test automation to ensure reliability and maintainability of the product.
Minimum Qualifications:
· Experience with modern frontend development, ideally using React and TypeScript.
· Good knowledge of JavaScript or TypeScript, HTML, and CSS.
· Understanding of web application architecture and integration with REST and gRPC APIs.
· Experience working with version control systems and development tools (e.g., Git, Bitbucket, Jira).
· Problem-solving skills and a collaborative mindset.
Nice to Have:
· Familiarity with C#/.NET or backend development concepts.
· Experience with UI test automation tools, such as Playwright.
· Understanding of microservices architectures and API design.
· Experience with cloud platforms (Azure, AWS, or Google Cloud Platform).
· Familiarity with containerization tools (Docker, Kubernetes).
· Familiarity with CI/CD pipelines and DevOps practices.

O ESETe
Spoločnosť ESET je globálnym lídrom v oblasti digitálnej bezpečnosti a je jedným z najväčších dodávateľov bezpečnostných riešení v Európskej únii. Zároveň je najväčšou a najoceňovanejšou IT firmou na Slovensku.
Už viac ako 30 rokov vyvíjame popredný softvér a služby zamerané na IT bezpečnosť a ochranu podnikov, kritickej infraštruktúry a domácností z celého sveta
Neustále hľadáme nové kolegyne alebo nových kolegov, ktorí chcú byť súčasťou úspešného slovenského príbehu s globálnym dopadom.
