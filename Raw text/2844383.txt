Responsibilities
Develop and maintain a complex Angular application used for regulatory processes in banking
Collaborate with cross-functional Scrum teams to design, implement, and deliver high-quality features
Ensure code quality with tools such as Karma, Jasmine, and JUnit (for backend testing)
Support continuous integration and delivery (CI/CD) via Jenkins
Engage in system design and improvements with tools like Figma
Work with backend services and workflows potentially involving Camunda, Drools, Apache Camel, and PostgreSQL
Requirements
At least 3+ years of experience with modern frontend framework/libraries (Angular) on large or complex code bases
Solid understanding of the JavaScript and web application ecosystem
Experience with Bootstrap, HTML, CSS
Comfortable with the SPA concepts
Experience with CI, CD and/or Unit Testing
Committed to performance, code quality, good practice and delivering high end products
Proficient with the GIT and its related tooling (branching flow, CLI commands etc.)
Technical and consumer awareness
Ability to troubleshoot problems in the team and for users
Analytical and good at time management
Great problem-solving skills
Works well in a team
Curious about new technologies and excited to find ways to implement them
Open minded and collaborative attitude
Strong command of English (both written and spoken)
Nice-to-have
Have experience with back end technologies / frameworks, such as node.js or Java and Spring Boot, Have good experience with Cloud service implementations, devops tools (Docker, Kubernetes)
