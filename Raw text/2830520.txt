Feladatok
Az Euroleasing digitális fejlesztéseiben való részvétel, end to end fejlesztési feladatok megvalósítása modern és AI támogatott módszerekkel.
Üzleti igények megvalósíthatósági elemzése, előkészítése.
Aktív részvétel infrastruktúra és architektúra fejlesztési feladatok tervezésében és kivitelezésében.
Együttműködés az üzemeltetést és fejlesztést támogató társterületekkel.
AI asszisztált fejlesztési eszközök használata (pl. GitHub Copilot, ChatGPT).
AI képességeket tartalmazó funkciók tervezése és implementálása.
Elvárások
Szakirányú informatikai vagy műszaki végzettség.
Legalább 5 év JAVA és PHP backend fejlesztési tapasztalat.
Több rétegű alkalmazások fejlesztésében szerzett tapasztalat.
SQL ismerete.
Jó problémamegoldó képesség, logikus gondolkodás, ügyfél‑ és szolgáltatásközpontú szemlélet.
Pontos, igényes munkavégzés.
Dokumentáció szintű angol nyelvtudás.
Microservice rendszerek ismerete.
Nyitottság AI‑alapú fejlesztési eszközök és módszerek használatára.
Előnyt jelent
Oracle és/vagy MSSQL adatbázisok ismerete.
Verziókezelők (GitHub, GitLab) ismerete.
Microsoft Azure ismerete.
CI/CD technológiákkal kapcsolatos tapasztalat.
Webes alkalmazások fejlesztésében szerzett gyakorlat.
REST API webservice tapasztalat.
Konténertechnológiák ismerete (Docker, Kubernetes).
Tesztelési eszközökben való jártasság.
AI‑modellek, AI‑szolgáltatások vagy ML‑alapismeretek.
