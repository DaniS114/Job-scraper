Job description, responsibilities and duties
Build and evolve mission-critical user interfaces
Design and implement frontend components for analytical dashboards and decision-support tools.
Translate complex data, simulations, and summaries into
clear and actionable user interfaces
.
Ensure frontend behaviour is predictable, robust, and aligned with operational use cases.
Contribute to frontend standards, patterns, and long-term maintainability.
Collaborate across architecture, design, and delivery
Work closely with the
backend engineer
and
technical leadership
to align frontend implementation with APIs, data contracts, performance considerations, and overall system architecture and delivery goals.
Collaborate with
designers
to turn design concepts into high-quality, production-ready UI.
Work with design tools such as
Figma
to understand layouts, interaction patterns, and design intent.
Understand how frontend, backend services, and data pipelines interact as a single system.
Provide feedback on feasibility, UX implications, and frontend constraints during solution design.
Work with complex, data-driven systems
Implement frontend logic for real-time or near-real-time data flows.
Handle data-heavy views, state management, and interaction patterns common in analytical platforms.
Understand how frontend applications operate within
cloud-based architectures
(e.g. APIs, authentication, deployments).
Be aware of how frontend decisions impact performance, scalability, and operational reliability in cloud environments.
Deliver with ownership
Take ownership of assigned frontend areas from design through implementation and iteration.
Be comfortable working with a high degree of autonomy in a small, senior-leaning team.
Identify frontend risks, usability issues, or technical debt and proactively address them.
Ensure frontend code is maintainable, testable, and production-ready.
