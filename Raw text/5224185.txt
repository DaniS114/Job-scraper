Purpose:
We are seeking a highly skilled and experienced
Senior Python Developer
to join our dynamic team in Kosice.
Our tools support essential projects such as MBfD and FTTH self-build, facilitating individual customer connections and outdoor collocations. Our diverse tool portfolio includes front-end assistants, add-ins, back-end services, and workflow systems, all operated on virtual machines.
In this role, you will contribute to the development and maintenance of robust software solutions that drive accurate cost calculations and streamline business processes. You will also be responsible for designing and maintaining thorough unit tests and end-to-end system tests, ensuring high-quality software delivery, however this position is
not focused on testing or test engineering alone
—we expect deep expertise in Python development combined with ownership of code quality through writing effective automated tests.
Additionally, you will help migrate libraries into a separate, globally accessible code repository, promoting reuse and consistency across projects.
What will you do?
Design, develop, and maintain new API endpoints and backend functionalities using Python 3 and associated libraries such as requests and json.
Build high-quality code with a
developer’s commitment to automated testing
, writing robust unit and end-to-end tests using the pytest framework—testing is integral but part of your development workflow, not a standalone testing role.
Drive enhancements and new features for our Mercury plugin and geo-server supporting geo-based planning.
Manage code repositories and continuous integration/deployment processes via GitLab CI/CD.
Collaborate with frontend developers and contribute where necessary to the client side.
You will succeed if you:
Must-have skills:
Extensive experience as a
Python developer
(Python 3), authoring backend services and APIs, with solid programming fundamentals including Object-Oriented Programming.
Strong knowledge and hands-on application of test-driven development and automated testing frameworks such as pytest.
Proficiency with modern frontend technologies (HTML, JavaScript, TypeScript, Vue.js, etc.) to support full-stack understanding.
Experience with geospatial data processing using PyQGIS.
Familiarity with development tools including Jira and GitLab for project and source code management.
Database skills (desired):
Experience with PL/SQL (Oracle), PostgreSQL, or MariaDB is a plus.
Language skills:
English language proficiency at upper-intermediate level (B2 or higher).
German language skills are advantageous but not mandatory.
