Állás leírása
Feladatok
az Állami Számvevőszék egyedi, PHP 8.x, Laravel 11.x, Livewire, PostgreSQL alapú modern webes alkalmazásainak fejlesztésében való részvétel;
„full stack”: adatbázis, front- és back-end fejlesztés;
a kódbázis színvonalának fenntartása automatizált és integrációs tesztekkel;
fejlesztői dokumentáció készítés;
együttműködés a társterületekkel.
Elvárások
szoftverfejlesztői munkakörben szerzett legalább kétéves tapasztalat és/vagy szakirányú végzettség;
SQL, HTML, CSS, JavaScript és GIT ismeret.
Előnyt jelent
Laravel PHP keretrendszerben szerzett tapasztalat;
GitLab gyakorlati ismeret;
MySQL és PostgreSQL-en kívül más adatbázisokkal szerzett tapasztalat;
Javascript, különösen Alpine.js, Vue.js tapasztalat;
Tailwind CSS tapasztalat;
adattárház rendszerek fejlesztésében szerzett tapasztalat;
docker/docker-compose felhasználói szintű ismeret;
python adat-analízis könyvtárak (numpy, pandas, stb) és/vagy R nyelv ismerete;
Playwright web teszt eszköz ismeret;
Filament PHP framework ismeret;
Linux felhasználói vagy adminisztrátori ismeretek;
Ansible vagy SaltStack tapasztalat.
Amit kínálunk
egy lendületes, együttműködő, egymást támogató, innovatív csapat szakmai munkájában való részvétel;
az Állami Számvevőszék modern technológiákkal (docker, CI/CD, automated testing, infrastructure-as-code) és metodológiákkal (Lean, Agile) megvalósuló fejlesztéseiben való részvétel;
folyamatos szakmai fejlődési, továbbképzési lehetőségek;
home office munkavégzés és rugalmas munkaidő;
munkatársak egészségének megőrzését támogató juttatások;
versenyképes jövedelem, egyéb béren kívüli juttatási csomag.
