Informácie o pracovnom mieste
Náplň práce, právomoci a zodpovednosti
Kto sme?
Sme slovenská technologická firma zo Žiliny, ktorá verí, že dobrá práca vzniká v prostredí, kde sa ľudia cítia dobre. Dlhodobo si budujeme otvorenú firemnú kultúru, založenú na spolupráci, dôvere a férových vzťahoch. Práve kvalitný tím a zdravá atmosféra sú pre nás základom úspechu.
Veríme, že kvalitné dáta a kvalitné vzťahy majú veľa spoločného – oboje potrebuje systematickosť, dôveru a dlhodobú starostlivosť.
Do nášho tímu hľadáme
Data Analytika/čku
, ktorý/á nám pomôže budovať moderné dátové riešenia a premieňať dáta na konkrétne výsledky.
Čo budeš robiť?
Navrhovať, vyvíjať a udržiavať dátové riešenia pre analytiku, reporting a základné ML použitia
Pracovať s relačnými databázami (MS SQL Server, PostgreSQL) – návrh schém, optimalizácia dotazov, práca s veľkými objemami dát
Zabezpečovať end-to-end Power BI reporting – od dátového modelu cez ETL až po publikovanie a správu datasetov
Využívať Python na analýzu dát, automatizáciu, prípravu dát a prototypovanie analytických/ML riešení
Implementovať základné ML modely (klasifikácia, regresia), robiť feature engineering a vyhodnocovať modely
Spolupracovať na zavádzaní engineering štandardov (verzovanie, reprodukovateľnosť, čitateľnosť kódu)
Aktívne komunikovať s biznisom – pochopiť potreby a pretaviť ich do funkčných a stabilných riešení
Podieľať sa na rozvoji dátovej infraštruktúry a moderných prístupov (ML, MLOps, LLM – podľa skúseností)
Čo od teba očakávame?
SQL (pokročilé) - MS SQL Server a PostgreSQL
Power BI (pokročilé) - Skúsenosť s end-to-end reportingom
Python - Denné používanie na analýzu a prípravu dát
ML základy - Algoritmy ako logistická regresia, Random Forest, PCA
Engineering štandardy - Git (branching, PR workflow, code review)
