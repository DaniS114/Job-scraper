Information about the position
Job description, responsibilities and duties
We are looking for a mid-level full-stack developer to join our team and work on an existing web application in the housing industry. Upgrade your career with us!
Your tasks:
To contribute to the design, development, and maintenance of the web applications.
FS Developer will work across the full technology stack, from database through to front-end, contributing to high-quality, accessible software that supports customer success and aligns with architectural standards.
Key Responsibilities:
Develop and maintain full-stack web applications using .NET (C#) Web API, Angular (TypeScript), and SQL Server.
Collaborate closely with architects, developers, and product teams
Implement features, fix defects, and enhance existing functionality
Ensure all deliverables conform to; accessibility (WCAG) and internal coding standards, and are responsive by default
Participate in code reviews and mentor junior-developers.
Strong focus on code quality, with a strong focus on delivering well-tested functional code with good error logging
Maintain and produce key technical documentation
Write unit, integration, and automation tests as required by policy
