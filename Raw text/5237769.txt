Aktuálne u nás vzniká nová príležitosť pre skúseného Senior systémového administrátora, ktorý bude zodpovedný za stabilnú, bezpečnú a efektívnu prevádzku serverovej a cloudovej infraštruktúry.
Vašou náplňou práce bude najmä:
Správa Windows serverov - inštalácia, konfigurácia a údržba Windows server infraštruktúry
Správa Active Directory - vytváranie a správa používateľov, skupín a organizačných jednotiek v AD
Microsoft 365 / Exchange Online - administrácia Exchange Online poštových schránok, distribučných zoznamov a hybridných konfigurácií
Správa Azure prostredia - prevádzka a rozvoj Azure infraštruktúry
Bezpečnosť - implementácia bezpečnostných štandardov, MFA a podmienenej politiky prístupu, správa MS Defender
Zálohovanie - nastavenie politík a pravidelné zabezpečenie systémových a aplikačných záloh
Automatizácia a dokumentácia - tvorba PowerShell skriptov pre automatizáciu a monitorovanie stavu systémov
Podpora - poskytovanie 2. a 3. úrovne podpory pre servery, sieť a služby Microsoft
