Céginformáció
A Talentis Group Zrt. flottakezelő partnere számára,
budaörsi munkavégzéssel, dinamikusan bővülő csapatába,
IT fejlesztő
munkatársat keres.
Feladataid lesznek
webes fejlesztési feladatok önálló és felelősségteljes elvégzése;
Laravel alapú rendszerek fejlesztése és karbantartása;
WordPress alapú weboldalak fejlesztés, karbantartás;
HTML, CSS, Bootstrap és PHP alapú elsősorban frontend (backend) fejlesztési feladatok;
státuszriportok készítése, dokumentálás;
az informatikai osztályra beérkező panaszok, problémák értelmezése, kezelése és szükség esetén saját hatáskörben a hiba elhárítása vagy továbbítása;
szaktanácsadás és javaslattétel új technológiák és megoldások tervezésében és bevezetésében.
Amit kérünk
HTML • CSS • LARAVEL • WORDPRESS • PHP • MYSQL • GitHub • Bootstrap• RestAPI • Javascript;
önálló, megbízható munkavégzés;
proaktivitás;
precizitás;
csapatszellem;
angol nyelvtudás.
Amit mi kínálunk
határozatlan idejű főállású munkaviszony;
stabil vállalati háttér és infrastruktúra;
versenyképes jövedelem;
munkába járási költségtérítés támogatás;
egymást segítő, vidám csapat;
átfogó betanulási program.
MUNKAHELYI EXTRÁK:
béren kívüli cafeteria juttatás;
étkezési lehetőség;
céges mobiltelefon és laptop;
dolgozói vásárlási kedvezmények.
