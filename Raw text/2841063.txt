Állás leírása
Responsibilities
Develop and maintain scalable web applications using Angular or React
Build and optimize RESTful APIs and microservices using Node.js, Java, or .NET
Define and manage cloud infrastructure using Infrastructure as Code, such as Terraform or OpenTofu
Work with relational (RDS, PostgreSQL) and NoSQL (DynamoDB) databases, ensuring security and efficiency
Ensure high-quality code through testing, code reviews, and best practices
Develop CI/CD pipelines for automated testing and deployment
Contribute to architecture discussions, ensuring efficient and cost-effective solutions
Collaborate in an Agile environment, actively participating in sprints and retrospectives
Requirements
Proven experience as a Full-Stack Engineer, delivering high-quality applications in production environments
Strong frontend expertise with Angular or React
Solid backend development skills with Node.js, Java (Spring Boot), or .NET
Proficiency with SQL and NoSQL databases, including query optimization
Familiarity with CI/CD pipelines, DevOps practices, and version control systems like Git
Experience with containerization (Docker) and orchestration tools (Kubernetes, AWS ECS)
Strong problem-solving skills, with a focus on performance, scalability, and user experience
Excellent communication and collaboration skills to work effectively across teams
Ability to write clear technical documentation and contribute to knowledge sharing
Experience managing cloud infrastructure using Infrastructure as Code, such as Terraform or OpenTofu, is a plus
Exposure to AWS services like Lambda, ECS, RDS, DynamoDB, S3, and API Gateway is beneficial

Book club & SnapSoft library, Board game club & regular board game evenings
