Náplň práce, právomoci a zodpovednosti
Máš rád vývoj, ale rovnako dôležití sú pre teba aj ľudia, s ktorými pracuješ? V Everlution veríme, že tie najlepšie riešenia vznikajú v uvoľnenej atmosfére a pri vzájomnom zdieľaní know-how. Do nášho tímu hľadáme PHP/Symfony developera, ktorý nám pomôže posúvať naš projekt na novú úroveň.
Čo u nás budeš robiť?
Vyvíjať moderné webové aplikácie s dôrazom na kvalitu a škálovateľnosť.
Pracovať na komplexnom tech-stacku.
Aktívne sa podieľať na návrhoch architektúry a riešení v rámci tímu.
Pravidelne „chit-chatovať“ s naším Scrum Mastrom z Londýna (v angličtine).
Tech Stack, ktorý používame:
Backend: PHP 8+, Symfony framework, TWIG templating system
API: REST API, Open API
Databázy: MySQL, Postgres, DynamoDB
Frontend: JavaScript/TypeScript, Ajax, Webpack
Infraštruktúra: Docker, Bref.sh (serverless), AWS (Lambda, SQS, API Gateway, CloudWatch, CloudFront, S3, RDS)
OS: Linux, MacOS

Skúsenosti: PHP 8+, Symfony framework
Dobrá znalosť REST API
Skúsenosti s relačnými databázami (MySQL alebo Postgres)
Implementácia a správa CI/CD pipeline
