Pre nášho klienta - dodávateľa pre automobilový priemysel hľadáme skúseného IT administrátora so špecializáciou na Windows servery a stanice. Ak sú tvoje skúsenosti z výrobnej spoločnosti určite to bude pre teba výhoda. Tvojou pracovnou náplňou bude:
- Podpora užívateľov a správa hw - desktop, laptop, android skenery, server
- Sprava prístupových práv - aplikácie
- Administrácia AD - používatelia, skupiny, prístupové práva
- Administrácia Lansweeper, PRTG
- Nastavenie zabezpečenia adresárovej štruktúry file servera
- Komunikačné služby – HW, služby / programy, MDM
- Aplikačná podpora pre sw SAP, MES systém, Profylax, Palstat, Human, TSS trace, NVR Hikhvision, Avigilon, MySQL...)
- Podpora systémového IT administrátora (Cisco, Meraki), správa sieťovej infraštruktúry
- Manažment licencií
- Podpora pri zavádzaní normy TISA
