About the Role
As an Application Engineer, you will design and develop backend and data services in Python on our Azure Datalake platform. You will help customers run accounting processes efficiently and generate data for critical reporting. This is a true DevOps role, where you own applications from development through production.
The team works with a lakehouse architecture using Azure Databricks, Azure Data Factory, and Azure Data Lake. Python is the primary language, with PySpark used for large-scale data engineering.
Responsibilities
Design and develop data transformation services and data flows using Python and PySpark.
Translate business requirements into technical specifications and robust solutions.
Design end-to-end applications integrating data from multiple domains and systems.
Plan and estimate work, breaking complex tasks into manageable deliverables.
Contribute to application architecture design and implementation.
Ensure quality through automated testing and code reviews.
Collaborate with stakeholders to deliver efficient and scalable solutions.
Apply Agile, Scrum, and DevOps practices throughout the development lifecycle.
Support operations during quarterly closing cycles.
Ensure solutions meet performance, reliability, and availability requirements.
