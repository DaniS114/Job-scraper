Information about the position
Job description, responsibilities and duties
We are looking for an experienced Data Engineer to join our team and contribute to the design, development, and optimization of a modern cloud-based data platform.
The role focuses on building reliable, scalable, and high-performance data pipelines using the following technologies:
Microsoft Azure
Microsoft Fabric
MS SQL / Azure SQL
Python / Spark (PySpark)
You will work on enterprise-grade data solutions supporting analytics, reporting, and further data-driven initiatives.
Key Responsibilities
Design and implement ETL/ELT processes
Develop and optimize data pipelines within Microsoft Fabric
Work with Spark / PySpark workloads
Design and optimize SQL databases (MS SQL / Azure SQL)
Data modeling (Data Warehouse / Lakehouse architecture)
Integrate data from internal and external systems
Collaborate with BI and analytics teams
Monitor performance, data quality, and reliability
Technical Skills
Minimum 3 years of experience in Data Engineering
Advanced SQL knowledge and query optimization skills
Experience with Azure data services
Experience with Microsoft Fabric or similar data platforms (Snowflake, Databricks)
Strong knowledge of Python and Spark (PySpark)
Experience with data modeling and DWH concepts
Nice to Have
CI/CD experience (Azure DevOps)
Experience with data governance tools
Experience with Power BI
Experience in enterprise environments
