Create data validation methods
Write, optimize, and maintain stored procedures

Work under Agile Framework (Scrum 2-week iterations)

Advanced T-SQL Coding and Python for data engineering

Familiarity with cloud-based ETL tools (AWS Glue or Azure data factory)
Familiarity with DWH and ETL concepts
Familiarity with Data Modelling concepts
Familiarity with Reporting and Analytical Tools (Snowflake, PowerBI)
Experience with Amazon Web Services or similar cloud environments
Knowledge of software versioning tools like Git
Experienced in core database development tuning techniques
Automation scripting and experience with SQLServer and PostgreSQL (plus)
Additional programming skills (.NET, Python, R, Scala) (plus)
Knowledge around Big Data concepts and data streaming architectures (plus)
Experience in sportsbook/betting or fintech sectors (plus)
Continuous learning mindset
Ability to prioritize and handle multiple tasks and projects
Excellent verbal and written English communication skills
