Azure Cloud Špecialist(k)a – UNIQA CZ/SK
O pozícii
Do nášho CZ/SK technologického tímu hľadáme
Azure Cloud Špecialist(k)a,
ktorý/á pomôže rozvíjať cloudové riešenia, automatizovať procesy a podporovať naše vývojové a prevádzkové tímy na ceste k modernému, bezpečnému a rýchlo doručovanému softvéru.
Azure Cloud špecialist(k)a zohráva v našom tíme kľúčovú rolu — spája vývoj, prevádzku, cloudové platformy a bezpečnosť s cieľom zabezpečiť rýchle, stabilné a bezpečné nasadzovanie aplikácií pre viac než 3 milióny klientov UNIQA v ČR a SR.
Pozícia je ideálna pre skúseného cloudového a DevOps inžiniera, ktorý chce aktívne ovplyvňovať architektúru cloudových riešení, prispieť k modernizácii našich aplikácií a byť súčasťou medzinárodných iniciatív v rámci UNIQA Group.
Čo bude náplňou vašej práce?
1. Budovanie a prevádzka CI/CD v Azure
tvorba, správa a optimalizácia CI/CD pipeline (YAML) pre aplikácie .NET, Java, integračné služby, API a interné systémy v Azure DevOps a GitHub
návrh release stratégie, branching modelov, deployment workflow pre viacero prostredí (Dev/Test/Prod)
integrácia bezpečnostných kontrol DevSecOps prístup a dodržiavanie štandardov bezpečnosti a compliance, ktoré sú pre finančný sektor kľúčové
2. Cloud Engineering & Infra as Code v Azure
návrh a nasadzovanie infraštruktúry v Azure pomocou
Terraformu
správa kľúčových Azure služieb:
App Services, API Management, Azure Functions
Azure Kubernetes Service (AKS), Container Registry
Azure SQL, Storage Accounts, Event Grid, Key Vault
Data Platform komponenty používané v rámci UNIQA (ADF, AML) — využívané v Data & AI tímoch UNIQA
3. Prevádzka a monitoring
nastavenie monitoringu (Azure Monitor, App Insights, Log Analytics)
proaktívne sledovanie stability služieb
riešenie incidentov, root‑cause analýza a automatizácia nápravných zásahov
optimalizácia nákladov (finops mindset), podpora cost governance pri cloudových riešeniach — téma preferovaná v rámci Data & AI tímov UNIQA
4. Automatizácia a skriptovanie
tvorba PowerShell/Bash skriptov na automatizáciu prevádzky, bezpečnosti a deploymentov
integrácia automatizovaných testov, static code analýz, bezpečnostných skenerov
5. Podpora vývojových tímov a metodika spolupráce
spolupráca s architektmi, Business Analystami, vývojármi a QA
účasť na návrhoch softvérových riešení, proof-of-concepts a pilotných projektoch
práca v agilnom prostredí (SCRUM/Kanban)
mentoring a šírenie DevOps kultúry v rámci lokálnych aj medzinárodných tímov
6. Bezpečnosť a compliance
zabezpečenie riešení podľa štandardov UNIQA Group Security
práca s identitami, prístupovými politikami a RBAC
ochrana citlivých údajov v súlade s reguláciami finančného sektora
