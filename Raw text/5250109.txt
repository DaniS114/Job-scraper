Information about the position
Job description, responsibilities and duties
You'll own quality across several projects at once. That means leading a small team of testers, staying hands-on yourself, and making sure defects don't reach clients.
We're looking for someone with at least 5 years in QA or testing roles, including some experience guiding others.
What you'll do
Lead a small QA team: plan the work, set priorities, allocate tasks, unblock people daily
Test software yourself: functional, regression, exploratory
Check that built features actually match the requirements and acceptance criteria
Find defects early, work with developers to fix them, verify the fixes
Write and maintain test scripts in Playwright; build automation where it genuinely saves time
Run and monitor tests through Jenkins pipelines, report results clearly
Write clear testing documentation for both developers and end users
Support clients and users during rollouts and production deployments
Report testing status clearly: what's covered, what's open, whether a release is ready
Run knowledge transfer or training sessions for end users when needed
What this role is not
It's not a pure management role. You'll be in the code and the test cases, not just in meetings.
