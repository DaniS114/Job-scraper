Új munkatársunk feladatai lesznek
- részvétel a fejlesztési és üzemeltetési architektúra elemzési, tervezési és kivitelezési folyamataiban
- backend rendszerek fejlesztése és karbantartása Java alapokon
- modern webes frontend alkalmazások fejlesztése React keretrendszerrel
- adatbázis műveletek tervezése és optimalizálása Oracle környezetben
- üzleti logika implementálása Spring Boot keretrendszer használatával
- jól karbantartható, dokumentált kód írása
- részvétel kód review folyamatokban és unit tesztelésben
- verziókezelés használata csapatmunkában
Amire a munkakör betöltéséhez szükség van

- minimum 2-3 év backend fejlesztési tapasztalat Java környezetben
- magabiztos Java Spring Boot ismeret
- react alapú frontend fejlesztési tapasztalat
- Oracle SQL adatbázis ismeret
- SQL Developer eszköz gyakorlati használata
- IntelliJ IDEA fejlesztői környezet ismerete
- Git verziókezelési ismeretek (GitLab)
