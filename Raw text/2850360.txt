Állás leírása
Responsibilities
Design, develop, test, document, and deploy high quality Salesforce solutions, leveraging the latest capabilities of the Einstein 1 Platform, Lightning Web Components, and modern Apex patterns
Analyze client specific requirements and define data model to support the business, reporting and technical requirements
Develop on demand Salesforce applications using Apex Classes, Triggers, Lightning Web Components (LWC), Flows, and integrations following Salesforce best practices
Participate in evaluating new CRM technologies, Salesforce product releases, and add ons (e.g., Data Cloud, DevOps Center, Salesforce Functions, Agentforce) and create plans for their adoption in Salesforce orgs
Proactively monitor new capabilities of Agentforce (AI Agents) with focus to build, extend or automate business workflows using Agent Actions, Prompt Templates, AI driven orchestration, and Einstein Copilot extensions
Provide ongoing technical support, optimization, troubleshooting, and maintenance for existing Salesforce customizations and configurations
Share knowledge on Salesforce development best practices (secure Apex, LWC patterns, CI/CD, modular architecture, performant Flows, integration patterns)
Leverage experience with .NET, Java, web services, and/or SQL Server to understand or build scalable integration points between Salesforce and external systems using REST, SOAP, Platform Events, or middleware
Requirements
Advanced Salesforce development experience with strong focus on Apex, Lightning Web Components and modern declarative automation (Flows)
Experience with Agentforce, including building or enhancing AI Agents, configuring Agent Actions, and using Prompt Builder or Einstein Copilot features is a strong advantage
Hands on experience with Java or C#, and solid understanding of HTML, JavaScript, CSS, and modern JS frameworks (e.g., ES6+, Node, or similar)
Experience with jQuery or other JavaScript frameworks is a plus, though modern JS and LWC experience is preferred
Salesforce Technical or Consultant Certification (e.g., Platform Developer I/II, JavaScript Developer I, AI Specialist, Data Cloud Consultant) is a strong advantage
Experience with DevOps Center, Git branching strategies, CI/CD, and automated testing is beneficial
Good communication skills, analytical thinking and the ability to work collaboratively
Advanced English language skills
Nice to have: German language skills
