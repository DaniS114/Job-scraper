Náplň práce, právomoci a zodpovednosti
Java Developer (Medior) – Data Migration & Validation Tool
Hľadáme Java developera, ktorý prevezme kľúčovú úlohu na masívnom migračnom projekte
pre nemecky Public sector
. Cieľom projektu je migrácia všetkých nemeckeho public sectora do jedného spoločného systému.
Tvojou úlohou nebude len "písať kód", ale
vyvíjať špecializovanú Java aplikáciu
, ktorá slúži ako automatizovaná "výstupná kontrola" migrácie. Budeš ten, kto povie:
"Áno, dáta boli prenesené správne a systém s nimi vie pracovať."
Čo budeš robiť (Tvoja misia):
Vývoj      Java validačnej aplikácie:
Tvorba a údržba nástroja,      ktorý testuje úspešnosť migrácie (cieľom je 95 % automatizácia kontrol).
Overovanie      dát (Data Integrity):
Písanie logiky, ktorá kontroluje migrované dáta priamo      v databáze (SQL) a porovnáva ich s transformačnými pravidlami.
API      Verifikácia:
Implementácia volaní na API cieľového systému –      overovanie, či sú zmigrované dáta pre nový systém "čitateľné" a      dostupné.
Analýza      požiadaviek:
Štúdium dokumentácie a mapovacích pravidiel (Data      Mapping) od klienta a ich preklad do technických kontrol.
Komunikácia      v nemčine:
Clarification hovory s klientom v nemeckom jazyku,      ujasňovanie si požiadaviek na validáciu a transformáciu dát.
Čo od teba vyžadujeme:
Kľúčová je kombinácia Java vývoja, silného analytického myslenia smerom k dátam a znalosť nemčiny.
Must-have:
Nemecký      jazyk (B2):
Nevyhnutnosť. Dokumentácia je v nemčine a budeš      komunikovať priamo s nemeckým klientom/tímom pri ujasňovaní požiadaviek.
Java      (Core/Backend):
Skúsenosť s vývojom backendových aplikácií (samostatný      vývoj logiky, nie len údržba).
SQL a      Databázy:
Schopnosť písať zložitejšie dopyty na overovanie      konzistencie dát.
REST      API:
Skúsenosť s integráciou a testovaním REST služieb (volanie endpointov,      spracovanie response).
Analytické      myslenie:
Schopnosť pochopiť komplexné transformačné pravidlá a      preklopiť ich do kódu.
Nice-to-have:
Skúsenosť      so Spring / Spring Boot (technológia, na ktorú sa môže prechádzať).
Skúsenosť      s migračnými projektmi alebo testovaním dát.
Anglický      jazyk (na internú komunikáciu, ak je potrebná, ale nemčina je primárna).
