Work independently and in a team

Write clean, high-quality, high-performance, maintainable and well documented code

2+ years of experience with .NET Core or .NET 6-7 and with Dependency Injection
Deep understanding of .NET memory management and how to write efficient code
Technical skills in OOP
Writing CLEAN code matching SOLID principles
Team player
Fluent written English
Fluent written and spoken Hungarian

Domain knowledge in crypto or high frequency trading (nice to have), Hands-on experience with Python and/or Powershell (nice to have), Building CI/CD pipelines (nice to have), REST APIs and WebSockets (nice to have), Test automation (nice to have), Fluent spoken English (nice to have)

Development done in a Kanban-like agile way
