Experienced Test Automation Engineer

POSITION
DESCRIPTION
Join our delivery team to build reliable, scalable test automation that accelerates releases and raises product quality. You’ll design BDD scenarios, engineer robust automation frameworks, and integrate tests into CI/CD so our teams ship confidently and fast.
WHAT WILL
YOU DO
•	Design and implement automated tests for web and service layers using Java, Selenium WebDriver, and Cucumber (BDD/Gherkin)
•	Develop test utilities and libraries (Java/Python) to improve reliability, data setup, and diagnostics
•	Integrate automation into CI/CD (e.g., Jenkins/GitHub Actions), track results, and surface actionable insights
•	Collaborate in agile ceremonies; translate user stories into executable BDD scenarios
•	Review PRs for testability, coach developers/testers on BDD, and help set pragmatic quality gates
•	Mentor junior team members and contribute to continuous improvement of testing practices
•	Troubleshoot issues in automated test scripts and continuously evaluate testing processes for efficiency
WHAT WE
EXPECT
•	2-5 years of  hands-on experience in building UI and API automation using Java + Selenium and Cucumber/BDD
•	Working knowledge of Python for utilities, data generation, or API checks
•	Solid grasp of testing fundamentals (test design, mocking/stubs, reliability, flakiness control)
•	Experience with version control (Git/GitHub) and CI/CD pipelines (e.g., Jenkins)
•	Comfort operating in agile teams; clear communication with engineers, analysts, and product stakeholders
•	Use test management tools (JIRA, HP ALM, TestRail) to plan, track, and report testing activities
•	Experience with ancillary tools (REST clients, SQL, reporting dashboards) and test data management
•	University degree in a Technology or Information Systems field
•	German language skills (spoken/written/B2+) – beneficial for client collaboration
•	Advanced English language (B2+)
