Responsibilities
Architect, build and maintain backend services and APIs using Python and web frameworks such as Flask or Django (or comparable)
Design and implement RESTful APIs / microservices, ensuring clean, maintainable, and efficient code, adhering to best practices (coding standards, documentation, testing)
Work closely with data‑science or ML/AI teams to integrate AI/ML models into production: build services that consume model outputs, manage inference pipelines, and support data‑driven features
Deploy and maintain AI/ML‑enabled applications and backend services using modern infrastructure: containers, cloud or on-prem environments, CI/CD pipelines, and orchestration tools
Optimize system performance, reliability, and scalability — including database design/management (SQL or NoSQL), API performance, asynchronous tasks, background jobs, caching or message‑queue integration
Collaborate with cross-functional teams (frontend, data scientists, product, DevOps) to gather requirements, translate them into technical solutions, and deliver features end‑to‑end
Ensure code quality, apply testing (unit, integration), participate in code reviews, maintain documentation and enforce best practices for maintainability and security
Requirements
Strong professional experience (e.g. 5+ years) developing backend services in Python at a senior level
Deep expertise with Flask or Django (or comparable) — building and maintaining production‑grade web applications / APIs
Solid understanding of RESTful API design, microservices architecture, database design (SQL or NoSQL), ORM frameworks or direct SQL, and data‑handling best practices
Familiarity with deployment practices: containerization (Docker), cloud services or infrastructure‑as‑code, CI/CD pipelines, testing, continuous integration and delivery
Strong coding practices: writing clean, modular, well‑tested, efficient, and maintainable code (adhering to standards such as PEP8 / SOLID / design patterns)
