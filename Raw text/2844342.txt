Állás leírása
Responsibilities
Design and implement security architecture for Azure Databricks platforms
Enforce Role-Based Access Control (RBAC) across Azure and Databricks environments
Integrate security into DevSecOps pipelines, ensuring automated security controls and policy enforcement
Manage and secure Azure resources, identities, and permissions
Partner with platform and data engineering teams to embed security best practices into deployments
Identify, assess, and remediate security risks and vulnerabilities
Support audits, compliance, and governance requirements
Create and maintain security standards, documentation, and runbooks
Requirements
Strong hands-on experience with Microsoft Azure security
Proven experience in DevSecOps practices and security automation
In-depth knowledge of Azure Databricks security concepts
Expertise in RBAC, including Azure AD and Databricks access controls
Solid understanding of cloud identity, access management, and least-privilege principles
Experience securing cloud-native data platforms at scale
Ability to operate independently in a senior-level role
Experience with Azure Key Vault and secrets management (nice to have)
Knowledge of network security, private endpoints, and secure connectivity in Azure (nice to have)
Familiarity with compliance frameworks (e.g., ISO, SOC, GDPR) (nice to have)
Azure security or cloud certifications (nice to have)
