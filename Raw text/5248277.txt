Information about the position
Job description, responsibilities and duties
Candidate will be responsible for designing, implementing, and maintaining an ALM software applications and services, with a strong emphasis on Python and Java development.
This role requires exceptional technical expertise in building scalable software solutions, integrating systems within the ALM toolchain, and contributing to continuous improvement across the full application lifecycle. You will collaborate closely with cross‑functional teams, ensure high‑quality code and maintainability, and support the evolution of an ALM ecosystem.
Major Responsibilities
Collaborate with cross‑functional teams to gather requirements, define technical specifications, and design effective software solutions within the ALM environment.
Design, develop, and maintain software applications and services using Python and Java, ensuring high performance, scalability, and reliability.
Implement and enforce architectural standards, coding guidelines, and best practices to support a robust and maintainable application landscape.
Develop and enhance frontend components using modern frameworks (e.g., React, Angular, or Vue.js) where required.
Build and maintain REST APIs, integrations, and automation routines to support ALM workflows and engineering toolchains.
Contribute to DevOps activities, including CI/CD pipelines, automated testing, deployments, and environment setup.
Continuously optimize existing applications for performance, usability, and code quality.
Provide technical guidance, mentoring, and support to other developers within the team.
Stay updated on the latest software development trends, tools, and technologies, and apply them to improve ALM solutions and processes.
