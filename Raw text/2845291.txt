Pontosan milyen feladataid lennének?
Vállalati szintű release-folyamatok megtervezése, ütemezése és koordinálása;
Release kalendárium kialakítása és karbantartása, ütközések és erőforrás-konfliktusok kezelése;
A fejlesztői, tesztelői, üzemeltetési és üzleti csapatok közötti kommunikáció biztosítása;
Build-, deploy- és verziókezelési folyamatok felügyelete;
Release-dokumentációk készítése (release notes, changelog);
Kockázatok, függőségek és visszagörgetési (rollback) tervek kezelése;
Release-automatizálási folyamatok támogatása, fejlesztése;
Incidenskezelés és problémakezelés támogatása release-ek során és után;
CI/CD pipeline-ok működésének felügyelete, optimalizálása;
Minőségbiztosítási és megfelelőségi követelmények betartatásának támogatása;
Szívesen megismerünk, ha
alapos Git ismerettel rendelkezel (branching strategy: GitFlow, Trunk based, Release branch model);
van tapasztalatod Build- és release-artifaktok verziókezelésében és -követésében (SemVer, date-based versioning);
rendelkezel Tagelés és release branch-ek kezelésében szerzett tapasztalattal;
magabiztos ismereted van az alábbi CI/CD rendszereket illetően: Jenkins, GitLab CI, Azure DevOps Pipelines, Argo CD/Flux (GitOps) és megérted a pipeline-ok működését, tapasztalatod van hibaelhárításban és deployment szakaszok felügyeletében;
ismered a Build és csomagolási folyamatok verziókezelését, mint Maven alapismeretek, Node.js és Angular build folyamatok ismerete, Docker image-ek buildelése és verziókezelése, Artifactory, Nexus vagy GitHub Packages használata;
alapos ismereteid vannak Deployment technológiák kapcsán az alábbi területeken: Kubernetes (helm chart kezelés, rollout stratégia), Cloud platformok: AWS, Azure, GCP, Deployment minták;
rendelkezel monitoring és minőségbiztosítási területeken szerzett tapasztalattal, loggyűjtő rendszerek ismeretével (ELK, Splunk, Grafana Loki), monitoring eszközök használatával (Prometheus, Grafana, Datadog, New Relic), ismerettel release utáni after-care folyamatok követésében KPI-ok alapján;
van tapasztalatod DevOps területen;
Containerek mélyebb ismerete nem okoz gondot;
szereztél tapasztalatot nagyvállalati release környezetben;
ITIL v3/v4 tudással is rendelkezel (Change Management);
automatizálási toolok (Python, Bash) használatában szereztél tapasztalatot;
rendelkezel legalább 3-5 éves gyakorlattal hasonló pozícióban;
