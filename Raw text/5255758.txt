Information about the position
Job description, responsibilities and duties
Are you passionate about building innovative applications that make a real impact? Join our dynamic team at the forefront of technology where you'll have the opportunity to work on diverse projects spanning from Reinsurance to Finance and HR, while developing your skills in both front-end and back-end technologies including exciting new AI capabilities!
About the Role
As a Junior Full-Stack Developer, you'll collaborate with experienced professionals to design, develop, and maintain applications that drive our business forward. You'll have the chance to work across the entire development stack while learning and growing in a supportive environment that values fresh perspectives.
Key Responsibilities
•	Develop and maintain responsive web applications using modern front-end frameworks (Angular / React)
•	Collaborate with senior developers to implement back-end functionality and APIs (.Net, C#)
•	Participate in code reviews and implement feedback to improve code quality
•	Learn and apply best practices in software development and cloud architecture
•	Troubleshoot and debug applications to ensure optimal performance
•	Contribute to technical documentation for applications and features
•	Support the continuous improvement of development processes and methodologies
About the Team
The Application Development Services team is responsible for 100+ applications serving multiple domains of the company - from Reinsurance to Finance or HR using agile methodologies. Applications are mostly based on Microsoft tech stack deployed to Microsoft Azure cloud platform. Our team consists of 30+ professionals based in Bratislava, Zurich, Munich and India.
